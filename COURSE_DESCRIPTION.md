# React: От основ к мастерству

React — это мощная библиотека для создания пользовательских интерфейсов, но освоение её концепций может показаться сложным для новичков.

Независимо от того, только начинаете ли вы изучать React или хотите углубить своё понимание, этот практический курс станет вашим проводником в мир современной фронтенд-разработки.

В этом курсе вы найдёте **100+ практических заданий**, каждое из которых фокусируется на конкретной концепции React. Вы получите глубокое понимание:

## Модуль 1: Ваш первый компонент
Научитесь создавать React-компоненты с нуля. Освоите базовую структуру компонентов, создадите карточку товара, список аватаров, блог-пост, кнопку действия и меню навигации.

## Модуль 2: Написание разметки с JSX
Погрузитесь в синтаксис JSX — расширение JavaScript для описания UI. Узнаете правила закрытия тегов, принцип единого корня, использование переменных и выражений в разметке, работу с className и атрибутами.

## Модуль 3: Передача пропсов
Освойте передачу данных между компонентами через props. Изучите деструктуризацию, значения по умолчанию, передачу объектов, массивов и специальный проп children.

## Модуль 4: Условный рендеринг
Научитесь показывать разный контент в зависимости от условий. Создадите приветствие для гостей, статусы товаров и доставки, уведомления о новых сообщениях, проверку уровня доступа и динамические стили.

## Модуль 5: Рендеринг списков
Освойте отображение массивов данных с помощью метода map(). Поймёте важность уникальных ключей, научитесь фильтровать списки и обрабатывать пустые состояния.

## Модуль 6: Чистые компоненты
Поймёте концепцию чистых функций в React. Узнаете, почему важна иммутабельность пропсов, как безопасно работать с локальными мутациями и избегать побочных эффектов при рендеринге.

## Модуль 7: Обработка событий
Научитесь реагировать на действия пользователя. Освоите работу с кликами, наведением, событиями форм, объектом event, методами preventDefault и stopPropagation, а также передачу обработчиков через props.

## Модуль 8: State — память компонента
Погрузитесь в управление состоянием с помощью useState. Создадите счётчики, переключатели, формы. Научитесь хранить в состоянии примитивы, объекты и массивы.

## Модуль 9: Состояние как снимок
Поймёте, как React работает с обновлениями состояния. Разберётесь с функциями обновления, замыканиями, батчингом и особенностями асинхронного поведения состояния.

## Модуль 10: Обновление объектов и массивов
Освойте иммутабельное обновление сложных структур данных. Научитесь обновлять свойства объектов, работать с вложенными структурами, добавлять, удалять и изменять элементы массивов.

## Модуль 11: Синхронизация с эффектами
Изучите хук useEffect для работы с побочными эффектами. Поймёте роль массива зависимостей, научитесь правильно выполнять cleanup и оптимизировать эффекты.

## Модуль 12: Манипуляция DOM с refs
Освойте прямой доступ к DOM-элементам через useRef. Научитесь управлять фокусом, выполнять прокрутку и хранить значения без перерисовки компонента.

## Модуль 13: Передача данных с Context
Изучите React Context для передачи данных без prop drilling. Создадите контексты для темы оформления, авторизации и глобального состояния приложения.

## Как проходить курс

Курс разделён на модули, каждый из которых содержит несколько практических заданий. Каждое задание включает:

1. **Файл проблемы** (`.проблема.jsx`) — стартовый код с комментариями и подсказками
2. **Файл решения** (`.решение.jsx`) — готовое решение для самопроверки
3. **Стили** (`style.css`) — готовые CSS-стили для красивого отображения

### Рекомендуемый подход:

1. **Прочитайте задание** — изучите комментарии в файле проблемы
2. **Попробуйте решить самостоятельно** — экспериментируйте и проверяйте результат
3. **Сверьтесь с решением** — если застряли или хотите узнать альтернативный подход
4. **Переходите к следующему** — двигайтесь последовательно по модулям

### Пререквизиты

Для успешного прохождения курса вам понадобится:
- Базовое понимание HTML и CSS
- Знание основ JavaScript (переменные, функции, массивы, объекты)
- Установленный Node.js (версия 16+)

### Запуск заданий

1. Клонируйте репозиторий курса
2. Установите зависимости: `npm install`
3. Запустите нужное задание: `npm run play <номер-задания>`

Например:
```bash
npm run play 01-01  # Первое задание первого модуля
npm run play 08-05  # Пятое задание восьмого модуля
```
